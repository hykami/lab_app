# Lab App

Настольное приложение на Python для поддержки работы лаборатории: ведение карточек проб, расчёты показателей, журналы и формирование документов.

> Публичная демонстрационная версия. Встроенные стартовые данные обезличены и предназначены только для ознакомления. Не используйте их как реальные производственные нормативы.

## Возможности

- графический интерфейс на PyQt6;
- локальное хранение данных в SQLite;
- расчёты и обработка лабораторных показателей;
- экспорт таблиц в Excel с помощью `openpyxl`;
- формирование документов Word с помощью `python-docx`;
- настройка карточек проб, силосов, культур и персонала.

## Требования

- Python 3.11 или новее (проект первоначально разрабатывался и проверялся автором на Python 3.14; совместимость с другими версиями следует проверить);
- pip;
- ОС с поддержкой PyQt6.

## Установка и запуск

1. Склонируйте репозиторий или скачайте его ZIP-архив.
2. Перейдите в каталог проекта:

   ```bash
   cd lab_app
   ```

3. Создайте виртуальное окружение:

   **macOS / Linux**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

   **Windows PowerShell**
   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

4. Установите зависимости:

   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

5. Запустите приложение:

   ```bash
   python main.py
   ```

При первом запуске приложение создаёт локальную базу данных `data/lab_app.db` и заполняет её демонстрационными начальными данными. Локальная база данных и файл `config.json` не предназначены для публикации в Git.

## Структура проекта

```text
lab_app/
├── assets/       # шаблоны документов и шрифты
├── data/         # инициализация SQLite

├── utils/        # вспомогательные функции
├── config.py     # локальные настройки
├── main.py       # точка входа
└── requirements.txt
```
